지금 상태와 다음 단계

이미 동작 중

Streamable HTTP MCP 서버(단일 /mcp 엔드포인트)에 도구 22개 · 프롬프트 2개가 등록되어 있고, 선택적 Bearer 토큰 인증·Origin 검증·Docker 배포·마크다운 무재빌드 갱신·한/영 문서까지 갖춰져 있습니다. PoC가 아니라 실제로 쓰고 있습니다(Phase 1·2 완료).

유의: 이 서버는 강제가 아니라 유도입니다. 최종 강제선(CI·린트·리뷰)은 그대로 두고, 그 앞단에서 위반 자체를 줄이는 보완입니다.

  1. 아직 연결하지 않은 프로젝트에 클라이언트 등록(1회 설정)을 추가합니다. — CLI: claude mcp add --transport http personal-rules <url>/mcp, Web: 저장소에 .mcp.json 커밋(공개 HTTPS 필요).
  2. 쓰면서 걸리는 규칙은 host_rules/ 마크다운을 고쳐 바로 다듬습니다(재빌드 불필요).
  3. 비어 있는 영역이 보이면 마크다운 하나 추가 + 도구 등록으로 확장합니다.
표준을 문서로 재워두지 말고, AI가 작업하는 순간 자동으로 쓰게 하자. 그러면 제멋대로는 사라지고 잘하는 데서만 다른 — 내 모든 프로젝트의 품질이 기억력에 의존하지 않고 올라간다.
