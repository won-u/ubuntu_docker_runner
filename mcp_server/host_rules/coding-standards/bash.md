# Bash / Shell Scripting Standards

당신이 작성하는 모든 셸 스크립트는 안전하고 이식성 있게 작성해야 합니다. `shellcheck` 통과를 기본으로 합니다.

## 1. 안전 옵션 (필수)
- 스크립트 상단에 `set -euo pipefail` 을 둡니다(오류/미정의 변수/파이프 실패 시 중단).
- shebang 은 `#!/usr/bin/env bash` 로 명시합니다.

## 2. 인용 · 변수
- 변수 확장은 **항상 큰따옴표**로 감쌉니다: `"$var"`, `"${arr[@]}"`.
- 외부/사용자 입력을 명령에 그대로 넣지 않습니다(인젝션 방지). 경로 인자는 `--` 로 옵션 종료.
- 상수는 대문자, 지역 변수는 소문자로. `readonly` 로 불변을 표현합니다.

## 3. 구조
- 로직은 **함수**로 분리하고, 함수 내 변수는 **`local`** 로 선언합니다.
- 종료 코드를 의미 있게 반환하고(성공 0), 실패 시 확인합니다.
- 명령 존재 여부는 `command -v <cmd>` 로 확인 후 사용합니다.
- 임시 파일은 `mktemp`, 정리는 `trap 'cleanup' EXIT` 로 보장합니다.
- **에러 메시지는 stderr** 로 출력합니다(`echo "..." >&2`).

## 4. 이식성
- POSIX sh 대상이면 bashism(배열, `[[ ]]`)을 피합니다.
- OS/셸별 차이가 있으면 주석으로 전제를 명시합니다.

## 5. 금지 · 주의
- 검증 없는 `eval`, 신뢰할 수 없는 입력의 워드 스플리팅, `rm -rf "$VAR/"`(빈 변수 시 위험) 같은 패턴을 피합니다.
